Genesys Messenger Mobile SDK

Add a native, fully featured mobile messenger solution to your Android app, powered by Genesys Cloud.

Overview

This API documentation extends our main documentation source on the Genesys Developer Center. Use Genesys Developer Center to find our Changelog and detailed feature flow explanations.

Getting Started

Follow the Messenger Mobile SDK for Android guide on the Genesys Developer Center for installation, deployment configuration, authentication setup, and end-to-end examples.

Chat Elements

Chat elements are delivered through ChatElementReceivedListener.onChatElementReceived. The received ChatElement can be cast to one of its subtypes for type-specific data.

  • ChatElement

  • ContentChatElement
