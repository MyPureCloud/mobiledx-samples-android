TrackingConfig

data class TrackingConfig(val appName: String, val appNamespace: String, val appVersion: String, val appBuildNumber: String, val deviceCategory: DeviceCategory, val deviceType: String, val osFamily: String, val osVersion: String, val isMobile: Boolean? = null, val screenHeight: Int? = null, val screenWidth: Int? = null, val screenDensity: Int? = null, val fingerprint: String? = null, val manufacturer: String? = null, val carrier: String? = null, val bluetoothEnabled: Boolean? = null, val cellularEnabled: Boolean? = null, val wifiEnabled: Boolean? = null, val externalId: String? = null, val traits: TrackingTraits? = null)

Session metadata applied to the tracker when MessengerAccount.initiateTracking is called.

Required fields are non-null; optional fields are nullable. Values are applied to the underlying tracker via its setters and are sent with every subsequent app event.
