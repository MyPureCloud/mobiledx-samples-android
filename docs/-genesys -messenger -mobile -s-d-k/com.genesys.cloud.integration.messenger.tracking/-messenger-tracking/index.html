MessengerTracking

class MessengerTracking

Fire-and-forget adapter around the Mobile Tracking SDK's MobileUserTracker.

Owned by MessengerAccount; the host obtains it via MessengerAccount.initiateTracking and calls events through account.tracking?.someApi(...). All event methods are non-blocking: they launch on an internal SupervisorJob scope and return immediately. Failures are handled inside the tracking SDK and are not surfaced to the host.
