Builder

class Builder

Builder for creating and configuring a ChatController instance.

Use the builder to register listeners and start the chat session. Call chatEventListener to register the host's event listener, then build with a configured AccountInfo to obtain the ChatController.

Usage:

val controller = ChatController.Builder(context)
    .chatEventListener(this)
    .build(messengerAccount, chatLoadedListener)
