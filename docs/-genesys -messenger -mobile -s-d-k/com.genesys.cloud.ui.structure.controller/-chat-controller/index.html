ChatController

class ChatController : ConfinedChatHandler

The primary entry point for integrating the Genesys Cloud chat experience into a host application.

ChatController manages the lifecycle of a chat session, including starting, ending, reconnecting, and presenting the chat UI. The host application creates an instance from a configured MessengerAccount using Builder, and registers a ChatEventListener to receive lifecycle callbacks.

Prerequisites:

  • A valid MessengerAccount configured with a deployment ID and domain.

  • A ChatEventListener passed to Builder.chatEventListener before calling Builder.build.

Usage:

val account = MessengerAccount(
    deploymentId = "your-deployment-id",
    domain = "your-domain.com"
).apply {
    logging = true
    sessionExpirationNoticeInterval = 300
}

val chatController = ChatController.Builder(context)
    .chatEventListener(this)
    .build(account, chatLoadedListener)

Important: Builder.build initiates the chat session and the chat UI Fragment is delivered via ChatLoadedListener.onComplete. Ensure the account is fully configured before calling it.
