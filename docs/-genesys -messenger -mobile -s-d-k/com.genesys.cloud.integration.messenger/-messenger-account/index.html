MessengerAccount

class MessengerAccount : AccountInfo

A concrete account configuration for connecting to a Genesys Cloud Messenger deployment.

MessengerAccount encapsulates all the configuration needed to establish a chat session, including the deployment identifier, domain, authentication credentials, and custom attributes.

Usage:

val account = MessengerAccount(
    deploymentId = "your-deployment-id",
    domain = "your-domain",
    context = applicationContext, // required for journey context / tracking
).apply {
    logging = true
    sessionExpirationNoticeInterval = 300
}

// Optionally configure authentication
account.setAuthenticationInfo(
    authCode = authorizationCode,
    redirectUri = "myapp://callback",
    codeVerifier = pkceVerifier
)

// Optionally initiate Mobile Tracking (requires Context above)
account.initiateTracking(
    TrackingConfig(
        appName = "MyApp",
        appNamespace = "com.example.app",
        appVersion = "1.0.0",
        appBuildNumber = "1",
        deviceCategory = DeviceCategory.MOBILE,
        deviceType = "phone",
        osFamily = "Android",
        osVersion = "14",
    )
)

val chatController = ChatController.Builder(context)
    .chatEventListener(this)
    .build(account, chatLoadedListener)

fun resetTrackingIdentity()

Host-controlled reset of the tracked visitor: clears the customer identifiers (external id and traits) and the journey session id on the active tracker, and rotates the device cookie used to identify the user. The tracker instance itself is preserved. Clearing identifiers is a no-op when tracking has not been initiated, but the device cookie is rotated regardless.
