InternalError

enum InternalError : Enum<InternalError>

Predefined human-readable failure messages exposed by the SDK for display in the host UI.

Each entry carries a default message string (with optional %s placeholders). Use format to substitute placeholder arguments and obtain the final string. These messages are intended for direct display to end users (for example, in a toast or alert) and are not machine-readable error codes — for programmatic error handling use the codes defined on com.genesys.cloud.core.utils.NRError.

Usage:

toast(context, InternalError.DeploymentInactiveStatusError.format())
