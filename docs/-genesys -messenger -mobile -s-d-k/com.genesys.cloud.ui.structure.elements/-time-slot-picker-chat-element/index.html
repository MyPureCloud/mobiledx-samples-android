TimeSlotPickerChatElement

class TimeSlotPickerChatElement : IncomingChatElement, StructuredInputElement

A chat element representing a scheduling picker with a list of available time slots.

Time slot pickers allow the user to select a meeting or appointment time directly from the conversation. Once a slot is selected, the SDK confirms the choice with the agent.
